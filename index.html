实时协商 · 共识 / 分歧 / 回抛本人
Envoy · 派我的 Agent 去对齐
AI 多 Agent 代理协作 · 探索作品
已上线

探索 AI 时代的「新社交」：协作不再是人对人，而是各自的 Agent 替本人把事谈拢—— 两个人的 Agent 实时协商，自动产出「共识 / 分歧 / 只有本人能拍板」三段对齐结果。放大人，而不是替换人。

上下文建模：事实自动化、意图人工确认。从材料自动抽取个人事实并附引用溯源，主观意图与底线显式交还本人确认，从机制上规避「代理越权替本人承诺」。
双 Agent 协商编排 + 防失真铁律。轮替发言、流式逐句生成，植入「暴露分歧不粉饰、未授权不代答应」两条约束，对齐结果归并为共识自决 / 分歧暴露 / 关键决策回抛本人。
意图保真 / 提效双评测 + 对照实验。真实场景验证代理自主消解 ~75% 决策点、用户底线 0 突破；对照实验界定「多 Agent 协作增益源于上下文异质性，而非模型多样性」。

测对儿CèDuì'r · AI 关系测评产品
multi-agent 多智能体报告引擎
已上线 · 可试玩

用 AI 测两个人的关系底色，恋爱、友情都能测。产出是 关系型号（类 MBTI）+ 逐项可验证的契合指数 + 7 个 Agent 实时写给彼此的 3 段心里话； 纯性格型号驱动、不掺玄学，定位在「性格匹配 / 情感分析 / 相处洞察」。 报告主打「分享卡截图金句 + 问 TA 实时回话 + 一键邀 TA 反测」做自传播引擎。

multi-agent

A1
链式分工，不用一个大 prompt 包打天下（Q→T→P）。测验解析 → 型号判定 → 报告撰写拆成三个专职 agent 顺序传递， 每个只负责一件事、各有独立 prompt 与出参校验，单点出错不会污染整份报告。
A2
心里话 3 路独立生成（Diary Pipeline ×3）。3 段心里话各跑一次 agent，分别绑定「想念→不安→渴望」的情绪锚和不同素材切面， 从结构上根治 LLM 写情感文案「三段一个调」的毛病。
A3
干扰项与正解同源产出。写正确解读的那次调用里，让 agent 在同一上下文顺手生成 3 个「同处境、不同动机」的干扰项， 4 选 1 才有真推理感，而不是从固定池盲抽。
A4
eval 闭环兜底（LLM-as-judge）。每个 agent 的输出先过一道 judge 打分——查穿帮断言、套话、跑题，不达标自动重跑或回退； 而契合算分交给本地确定性代码，LLM 只负责语言、不碰数字，保证契合指数可复现、明细可验证。

关键决策

01
定位反「玄学黑箱」。产品定位为「性格匹配 / 情感分析 / 相处洞察」，纯性格型号驱动、不做黑箱套话； 底层不做 mock 套话、每一分可追溯，这是这类产品站得住的前提。
02
透明算分，可验证才可信。契合指数 = 型号 4 维度匹配 + 关系状态加成， 每一项贡献分摊开给用户看，明细相加严格等于总分。可验证 = 可信任 = 可分享。
03
描述→判型，不让用户自己选。用确定性算法把原型 / 性格标签 / 一句话描述判定成 4 字母型号（同输入同结果）， 再用牵红线小游戏揭晓——把「被算法看穿」做成有仪式感的钩子。
04
3 段心里话：emotion + focus 双锚点。解决 LLM 写情感文案两大病——三段一个调、瞎编一次性事件。 用情绪锚（想念→不安→渴望）加素材切面分轨，禁止「你昨天做了 X」这类穿帮断言，只改写 TA 的习惯模式。
05
4 选 1 干扰项同源生成。旧版从固定池随机抽，干扰项跟此刻处境无关、像盲猜； 改为后端 prompt 同步输出 3 个「同处境同语气、不同动机」的干扰项，4 选 1 才有真推理感。
06
报告 = 增长引擎，不是结论页。canvas 生成的契合分享卡（截图金句 + CP 名）+ 问 TA 实时回话 + 一键邀 TA 反测， 为朋友圈 / 小红书自传播专门设计；北极星就是主动分享率。

How I Work

做产品的方法

01
问题先于功能
每个决策前先问「这个为谁解决什么」。用 office-hours 六问、premortem 找飞轮反向，宁可砍掉一个 feature 也不做模糊需求。
02
eval 是地基，不是补救
AI 产品没有 eval 就只能靠 vibe。一开始就建可量化指标、同口径 baseline 与 LLM-as-judge，每次迭代都跑分、留痕可复盘——大模型评测项目的 70→92、测对儿用 multi-agent 把 JSON 解析失败率从 12% 压到 2% 都是这么来的。
03
端到端，亲手做完一遍
PM + Design + Eng + Prompt 一个人闭环。不是炫技，是「懂代价」才能做出「懂代价的决策」。
04
传播写进产品里
不靠投放，靠产品本身让人想分享。截图金句、双向反测、社交对照，分享机制是设计阶段就植入的核心交互，不是事后加的按钮。
